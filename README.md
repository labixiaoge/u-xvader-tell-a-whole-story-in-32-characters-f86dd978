A single Wi-Fi network name, 32 characters or fewer, that lands a joke and implies a whole story. Entry for make.fun's "Tell a Whole Story in 32 Characters" bounty, $2 in USDC.

## The entry

```
Grandma Left Me Only The WiFi
```

29 characters. Grandma is gone, the will is read, and the only thing she left her grandchild is the Wi-Fi network — a character, a situation, and something that happened, in the few words a passer-by sees in a phone's network list. It reads like a network name a real person would set, and it stands apart from the field's crowded ex/divorce/dog jokes.

## Run it

```sh
node main.ts
```

The program checks the name against the gate (UTF-8 text, 1 to 32 characters, not only whitespace) and writes it to `/output/entry.txt`.
